# 🏦 Bank Customer Churn Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Bank Customer Churn Analysis Dashboard** developed using **Microsoft Power BI**.

The objective of this project is to analyze customer churn patterns, identify the key factors associated with customer attrition, and provide actionable business insights that can help a bank improve customer retention.

The dashboard transforms raw customer data into interactive visualizations and KPIs that make it easier to understand customer behavior and churn trends.

---

## 🎯 Project Objectives

* Analyze overall customer churn.
* Identify the percentage of customers who have exited the bank.
* Understand churn patterns across different customer segments.
* Analyze churn based on demographics and account characteristics.
* Identify factors associated with higher customer churn.
* Create an interactive dashboard for business decision-making.

---

## 📊 Dashboard Highlights

The Power BI dashboard includes analysis of:

* 👥 Total Customers
* 🚪 Churned Customers
* 📈 Churn Rate
* 💰 Customer Balance
* 💳 Credit Score
* 👤 Customer Age
* 🌍 Geography
* ⚥ Gender
* 🏦 Number of Products
* 💳 Credit Card Status
* ⭐ Active Membership
* 📅 Customer Tenure

Users can interact with the dashboard using filters and slicers to analyze different customer segments.

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks important KPIs such as:

| KPI                  | Description                              |
| -------------------- | ---------------------------------------- |
| Total Customers      | Total number of customers in the dataset |
| Churned Customers    | Number of customers who exited           |
| Churn Rate           | Percentage of customers who churned      |
| Active Customers     | Customers who are currently active       |
| Average Balance      | Average customer account balance         |
| Average Credit Score | Average credit score of customers        |
